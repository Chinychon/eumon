## Design Specificity Verdict
Generic skin, specific content: pure #000, Geist + uppercase mono, 1px hairlines, zero radius, one jade accent is the 2024–26 dev-tool console. Product character lives in the run track, split bar, dim-folder/bright-slug paths, stall diagnosis, IME-safe Enter. ~95% of every view is literal black; surface steps 1.06:1 and 1.12:1; hairlines 10%; charts gray by rule; amber alarm-only; no imagery. DESIGN.md's Square, Dark-Only and Flat Sheet rules produce the "too black, too hard" reaction, so polish won't fix it; the rules must change.
Deterministic scan: CLI clean with config (overused-font waived: Geist pinned). Browser: Overview 24 flagged elements (10px pills, 11–11.5px secondary text, 150–180-char finding lines, h2→h4 skip, em-dash overuse mostly from analysis text); Ask 2 (95-char lede, overused font); Ask thread 4 (line length, h1→h3 skip, 8 em dashes from the model); Data 2 (43-char uppercase label). False positive: dark-glow from the detector's own overlay. Overlay left visible in the [Human] tab on Overview.

## Priority Issues
- [P1] Cold, hard feel is codified in the rules. Fix: paper (Adaline/Cofounder) + warm-night themes, stepping surfaces, soft radii, depth, small nature chart palette, tokenize 19 hard-coded colors, rewrite DESIGN.md rules. Command: /impeccable colorize, /impeccable document.
- [P1] Ask page bombards instead of welcoming (long lede, big composer, 5 chips, bold "Continue…" truncating on phones, 10 thread rows with delete each; dead-end answers; follow-ups stream below the sticky composer). Fix: PostHog-style centered start (seedling, greeting, one composer, 3–4 chips, 2–3 quiet recents), follow-up chips + Retry, scroll-follow, heading order. Command: /impeccable distill, /impeccable onboard.
- [P1] Motion missing where it carries information (poll jumps, invisible row arrival, static bars, instant drawer and report). Fix: motion system with the pixel crawl garden as the focal moment (sprout per URL, bloom at finish), tweened counts, drawn checks, growing bars, drawing lines, sliding drawer, ≤300ms interactions, reduced-motion paths. Command: /impeccable animate, /impeccable delight.
- [P1] The long wait has no control and no ending (no Cancel; no estimates; post-crawl valley; silent swap). Fix: Cancel run with confirm, estimates on Update vs Re-crawl, collapse finished crawl, finish strip with deltas. Command: /impeccable harden, /impeccable layout.
- [P2] Accessibility and phone gaps (drawer focus not returned, phone sheet not modal, DOM vs visual order, 1.54:1 control borders, mouse-only chart readout; no site switcher on phones; push drawer squeezes 1100–1439px). Command: /impeccable adapt, /impeccable audit.
